# CKA Notes 寫入規則

## 筆記結構

- 每條筆記用 `##` 標題，標題寫重點或關鍵字
- 內容簡短，1-3 句為主
- 可加 code block 記指令或 yaml 片段
- 不分類，flat 結構，新筆記加在最後

## 什麼該記

- 做題時卡住或花太多時間的點
- 踩過的坑、容易搞混的概念
- 省時技巧、好用的 alias 或 one-liner
- 題目陷阱或 tricky wording

## 什麼不用記

- 已經很熟的基本操作
- 純粹手誤造成的錯誤
- 與考試無關的延伸知識

## 格式偏好

- 標題用關鍵字，不用完整句子
- 內容直接講結論，不需要背景鋪陳
- 指令用 code block，yaml 片段標註 `yaml`
