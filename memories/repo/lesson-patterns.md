# Lesson Patterns

- Command drill 設計可保留一題「需靠輸出推理資源關係」的觀察題，價值在於讓使用者用名稱前綴與 label 把 Pod 對回 ReplicaSet，而不是只找直接答案。
- 2026-03-16 Deployment lesson 的 Pod/ReplicaSet 題型有效：先看 Pods with labels，再要求把 `pod-template-hash` 與 ReplicaSet 名稱連起來，能訓練從輸出拼管理鏈的能力。
- 對 command drill 而言，這類題目比直接問定義更能驗證是否真的看懂 Deployment -> ReplicaSet -> Pod 的執行期對應。
