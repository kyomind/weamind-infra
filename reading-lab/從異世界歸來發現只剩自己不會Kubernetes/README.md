# 從異世界歸來發現只剩自己不會Kubernetes

這是這本書的專屬工作區。

## 結構

1. `sources/`：放原始照片、截圖與其他不能同步到 Git 的素材。
2. `outputs/`：放可以同步、可以整理、可以反覆展開的內容。
3. `archive/`：放已經退役、被新版取代，但仍想保留的舊整理稿或實驗版本。

## 目前可同步內容

1. `outputs/00-prework-master-outline.md`：這本書目前的主題總綱。

## 使用原則

1. 原始素材只留在 `sources/`，不要把圖片內容當成可公開資產。
2. 之後若要再拆 prework 或整理稿，優先放進 `outputs/`。
3. 退役內容移到 `archive/`，例如過期總綱、被新版本取代的初稿、暫時不再使用的實驗性整理。
4. 如果未來這本書再衍生出新的整理階段，也直接在這個子資料夾底下擴充，不要把東西散到別的學習系統。
