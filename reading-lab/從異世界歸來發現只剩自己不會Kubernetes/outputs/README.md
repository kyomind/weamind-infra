4. `03-prework-service-observability.md`：Service 與本地觀察通道。

## 建議順序

1. 先看 `00-prework-master-outline.md`，確認整體地圖。

3. 如果要按建議順序走，優先從 Pod 生命週期與 Cluster 元件兩份開始。
