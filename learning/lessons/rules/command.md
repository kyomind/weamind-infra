# Command Drill Rules

## 適用時機

讀取本檔處理 `03-command.md` 的建立、互動與回填。

## 檔案用途

`03-command.md` 記錄指令練習。重點是讓之後複習時快速看懂：

1. 當時在驗證什麼
2. 看到了什麼關鍵輸出
3. 因此能下什麼結論

## 建立原則

先判斷今天是否需要 command drill。

需要時，建立 lesson 骨架時一次寫出預計輪次。常態 lesson 預設 2 到 4 輪。

每輪應形成一個最小閉環：問題、候選指令、實際指令、關鍵輸出、使用者選擇理由、AI 判讀、一句話收斂、狀態。

## 互動節奏

每一輪：

1. AI 給明確情境，說清楚這輪要驗證什麼。
2. AI 提供 3 個可選指令，放在同一個 `bash` code block。
3. 使用者選一個指令，到真實環境執行，回覆輸出與選擇理由。
4. AI 判讀輸出、修正理由，收斂成一句可複習的結論。

command drill 的學習價值包含試錯。若使用者選了不夠精準但合理的指令，保留選擇、判讀與修正過程。

## 記錄原則

- 指令與輸出統一使用 `bash` code block。
- 原始輸出很長時，摘錄最有判讀價值的 3 到 8 行。
- 每輪只保留完成判讀所需的最小內容。
- 額外追問或延伸補充整理到 `05-note.md`。
- `AI 判讀與修正` 主動加粗關鍵句、關鍵詞或判讀口訣。
- 技術術語、狀態名、欄位名、資源名使用 inline code。

## AI 輔助驗證

`03-command.md` 的練習預設由使用者親手操作。

AI 可以在需要時執行輔助驗證。記錄時標示為輔助驗證，並和使用者親手完成的 command drill 分開。

最小完成條件是使用者至少親手完成一輪操作、貼回輸出，並說出選擇理由。
