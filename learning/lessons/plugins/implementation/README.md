# Implementation Lesson Plugin

這個子目錄負責 implement-heavy lesson 的 mode、骨架與 `06-implementation.md` 帶法。

## 文件分工

- `AGENTS.md`：implementation 類文件的 agent 工作規則與責任邊界。
- `implement-heavy-mode.md`：implement-heavy mode 的適用情境、lesson flow，以及和 QA / report 的關係。
- `implement-heavy-lesson-template.md`：`01-outline.md` 與 `06-implementation.md` 的初始化骨架。
- `implementation-guide.md`：`06-implementation.md` 的實際帶法，例如 session 開場、step 推進、提問邊界與回填原則。

## 一句話定位

- mode 檔回答「什麼時候用 implement-heavy」。
- template 檔回答「骨架怎麼長」。
- guide 檔回答「`06-implementation.md` 實際怎麼進行」。
